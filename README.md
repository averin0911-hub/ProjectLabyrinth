# ProjectLabyrinth — руководство пользователя

ProjectLabyrinth позволяет создавать и редактировать лабиринты, наблюдать
за поиском пути и сравнивать пять алгоритмов: BFS, двунаправленный BFS,
Дейкстру, A* и DFS.

## 1. Запуск программы

Скачайте проект и распакуйте архив. В корневой папке находятся готовые
приложения для Windows и Linux x64. Для готовых приложений отдельно
устанавливать Python и PyQt6 не требуется.

### Windows

Откройте файл **`ProjectLabyrinthWin.exe`** двойным щелчком.

### Linux

Откройте терминал в папке проекта и выполните:

```bash
chmod +x ProjectLabyrinthLinux
./ProjectLabyrinthLinux
```

Первую команду достаточно выполнить один раз после скачивания файла.
Совместимость готовой Linux-сборки зависит от системных библиотек
дистрибутива. Если она не запускается, используйте запуск из исходников.

### Запуск из исходников

Для этого способа нужен Python 3.10 или новее. Все команды выполняйте
в папке проекта, где находится `gui.py`.

**Windows, PowerShell — первый запуск:**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe gui.py
```

**Linux — первый запуск:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gui.py
```

При последующих запусках выполняйте только последнюю команду для своей
системы. При открытии программы автоматически создаётся лабиринт 21 × 21.

## 2. Быстрое начало

1. Дождитесь появления начального лабиринта в центральной части окна.
2. Слева в блоке **«Алгоритм»** выберите, например, **BFS**.
3. Выберите режим **«Анимация»** и нажмите **«Запустить»**.
4. Наблюдайте за исследованием клеток и появлением жёлтого пути.
5. Справа посмотрите длину пути, количество обработанных клеток и время.
6. Нажмите **«Сравнить алгоритмы»**, чтобы получить результаты всех пяти
   алгоритмов для этого же лабиринта.

Слева расположены настройки и кнопки управления, в центре — лабиринт,
справа — результаты и легенда. Нижняя строка показывает сообщения о работе
программы и координаты старта и выхода.

## 3. Создание лабиринта

В блоке **«Параметры лабиринта»** задайте:

| Параметр | Что он означает |
| --- | --- |
| Ширина | Число столбцов вместе с внешними стенами, от 5 до 2001 |
| Высота | Число строк вместе с внешними стенами, от 5 до 2001 |
| Удаление стен | Вероятность открытия подходящих внутренних стен, от 0 до 100%; увеличение значения добавляет обходные пути |
| Seed | Число для повторяемой генерации или значение «Случайный» |

Нажмите **«Сгенерировать»**, чтобы заменить текущий лабиринт новым.
Изменение полей ввода само по себе не изменяет уже созданный лабиринт.

Чтобы повторить лабиринт, используйте одинаковые ширину, высоту, seed и
процент удаления стен. При значении **«Случайный»** программа выбирает
новое случайное начальное состояние генератора.

При размере от 600 клеток хотя бы по одной стороне появится запрос
подтверждения. Большие лабиринты требуют больше времени и оперативной памяти.
Во время расчётов часть элементов управления временно недоступна.

## 4. Редактирование лабиринта

В блоке **«Редактор»** выберите инструмент в поле **«Инструмент»**.

| Инструмент | Действие левой кнопкой мыши |
| --- | --- |
| Стены / проходы | Щелчок превращает проход в стену, а стену — в проход |
| Старт | Щелчок по свободной клетке переносит туда зелёный старт |
| Выход | Щелчок по свободной клетке переносит туда красный выход |

Для изменения нескольких клеток зажмите левую кнопку и ведите мышью.
Действие определяется первой клеткой: если начали с прохода, рисуются
стены; если со стены — проходы.

Внешнюю рамку изменять нельзя. Старт и выход можно ставить только на
свободные клетки; закрасить маркеры стенами или совместить их нельзя.

- **«Откатить клетку (Ctrl+Z)»** отменяет последнее изменение одной клетки
  или перенос маркера. Каждое нажатие Ctrl+Z делает один откат.
- **«Очистить поле»** убирает внутренние стены, сохраняя внешнюю рамку,
  старт и выход.

При создании или загрузке другого лабиринта история откатов начинается
заново. Редактирование текущего лабиринта сбрасывает подсветку поиска.

Координаты внизу окна записаны как **(строка, столбец)**, начиная с нуля.
Например, `(1, 2)` означает вторую строку и третий столбец.

## 5. Масштаб и прокрутка

Меняйте значение **«Масштаб»** от 5 до 200% или удерживайте **Ctrl** и
вращайте колёсико над лабиринтом. При наведении на лабиринт масштабирование
ориентируется на точку под указателем мыши.

Если лабиринт не помещается в видимую область, перемещайтесь по нему
полосами прокрутки. Уменьшите масштаб, чтобы увидеть больше клеток.

## 6. Поиск пути

Выберите один из пяти алгоритмов и нажмите **«Запустить»**.
BFS, двунаправленный BFS, Дейкстра и A* ищут кратчайший путь.
DFS находит путь, но его длина может быть больше минимальной.
Движение выполняется между соседними клетками по стороне, без диагоналей.

Доступны два режима:

- **«Анимация»** — сначала показывается исследование клеток,
  затем найденный путь подсвечивается жёлтым.
- **«Мгновенно»** — после расчёта сразу показываются обработанные клетки
  и найденный путь.

Расчёт завершается до начала анимации. Если после нажатия кнопки отображается
сообщение **«Выполняется поиск…»**, дождитесь результата.

### Управление просмотром

| Элемент | Действие |
| --- | --- |
| Пауза / Продолжить | Приостанавливает или продолжает воспроизведение |
| Шаг | Останавливает автоматическое воспроизведение и показывает следующий шаг поиска или следующую клетку итогового пути |
| Сбросить анимацию | Убирает подсветку поиска и пути, сохраняя сам лабиринт |
| Задержка между шагами | Задаёт паузу от 0 до 1000 мс; меньшее значение ускоряет воспроизведение |

Для пошагового просмотра можно сразу нажать **«Шаг»**, без предварительного
нажатия **«Запустить»**. Программа рассчитает поиск и покажет первый шаг.
Последующие нажатия продолжат просмотр. Одно событие поиска может менять
состояние уже показанной клетки, поэтому каждый шаг не обязательно
добавляет новую клетку на экран.

Смена алгоритма сбрасывает прежнее воспроизведение. Для нового алгоритма
нажмите **«Запустить»** или **«Шаг»**.

Если выход недостижим, в результатах появится **«Нет пути»**. При этом
просмотр обработанных клеток и управление анимацией остаются доступны.

### Обозначения цветов

| Цвет | Значение |
| --- | --- |
| Тёмный | Стена |
| Белый | Свободная клетка |
| Зелёный | Старт |
| Красный | Выход |
| Фиолетовый | Открытый список — клетки, ожидающие обработки |
| Голубой | Закрытый список — обработанные клетки |
| Жёлтый | Найденный путь |

## 7. Результаты и сравнение алгоритмов

В таблице **«Последний запуск»** показаны:

- выбранный алгоритм;
- длина пути в переходах между клетками;
- количество обработанных клеток;
- время расчёта в миллисекундах.

Например, путь из трёх клеток имеет длину 2. Время расчёта не включает
длительность показа анимации.

Чтобы сравнить алгоритмы, нажмите **«Сравнить алгоритмы»** в правой части
окна и дождитесь сообщения **«Сравнение завершено»**. Таблица
**«Последнее сравнение»** покажет длину пути, количество обработанных клеток
и время для каждого из пяти алгоритмов на текущем лабиринте.

Каждое сравнение выполняет по одному запуску алгоритмов. Для исследования
времени работы повторите сравнение несколько раз: результаты замеров
могут немного различаться.

## 8. Сохранение и загрузка

### Сохранить лабиринт

1. Нажмите **«Сохранить в файл»** в блоке **«Файлы»**.
2. Выберите папку и имя файла с расширением `.json`.
3. Подтвердите сохранение и дождитесь сообщения **«Лабиринт сохранён»**.

Сохраняются стены, проходы, старт и выход. Для сохранения результатов
сравнения или вида подсветки сделайте снимок экрана.

### Загрузить лабиринт

1. Нажмите **«Загрузить из файла»**.
2. Выберите JSON-файл лабиринта и подтвердите выбор.
3. Дождитесь сообщения **«Загружен лабиринт…»**.

Примеры файлов находятся в папке `saves/`. Максимальный размер
загружаемого файла — **10 МиБ**. При ошибке формата или превышении
ограничений программа покажет сообщение; текущий лабиринт останется на месте.

Для переноса лабиринта между компьютерами сохраните его в JSON и откройте
этот файл в программе на другом компьютере.

## 9. Завершение работы

Если хотите продолжить работу с текущим лабиринтом позже, сохраните его
в файл перед закрытием окна: автоматического сохранения нет.

Закройте окно обычной кнопкой закрытия. Если идёт генерация, поиск или
сравнение, дождитесь завершения расчёта и закройте окно повторно.
