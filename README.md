# ProjectLabyrinth

Учебное приложение на Python и PyQt6 для поиска пути в лабиринте,
визуализации работы алгоритмов и сравнения их результатов.

## Возможности

- Генерация лабиринтов с настройкой размера, удаления стен и seed.
- Редактирование стен и проходов мышью, ручная установка старта и выхода.
- Поиск с помощью BFS, двунаправленного BFS, Дейкстры, A* и DFS.
- Анимация открытого и закрытого списков, подсветка найденного пути.
- Пауза, просмотр по шагам, настройка задержки и мгновенный показ результата.
- Сравнение алгоритмов на одном лабиринте по длине пути, числу обработанных
  клеток и времени расчёта.
- Сохранение и загрузка лабиринтов в формате JSON.
- Масштабирование, прокрутка и откат редактирования через Ctrl+Z.

BFS, двунаправленный BFS, Дейкстра и A* предназначены для поиска кратчайшего
пути. DFS находит допустимый путь, но не гарантирует его минимальную длину.
Перемещение разрешено между соседними клетками по стороне, без диагоналей.

## Установка и запуск

Для запуска из исходников нужны Python 3.10 или новее и PyQt6.
Скачайте проект или клонируйте репозиторий. Все команды ниже выполняются
из корневой папки проекта, где расположен `gui.py`.

### Windows — PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe gui.py
```

### Linux — Bash

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gui.py
```

При запуске автоматически генерируется лабиринт 21 × 21.

## Работа с программой

### Генерация и редактирование

Задайте ширину и высоту и нажмите **«Сгенерировать»**. Размеры включают
внешнюю рамку. Параметр **«Удаление стен»** задаёт вероятность открытия
подходящих внутренних стен после генерации коридоров; это не доля всех
стен, которые обязательно будут удалены.

В поле **Seed** выберите число для повторяемой генерации. Одинаковые seed,
размеры и процент удаления стен воспроизводят один лабиринт в текущей
реализации генератора. Значение **«Случайный»** создаёт новый случайный вариант.

| Действие | Управление |
| --- | --- |
| Изменить стену на проход или проход на стену | Выберите «Стены / проходы» и нажмите левой кнопкой мыши |
| Изменить несколько клеток | Зажмите левую кнопку и ведите мышью; действие определяется первой клеткой |
| Перенести старт или выход | Выберите «Старт» или «Выход» и нажмите на свободную клетку |
| Отменить последнее изменение клетки | Ctrl+Z или кнопка «Откатить клетку» |
| Убрать внутренние стены | Кнопка «Очистить поле» |
| Изменить масштаб | Поле «Масштаб» или Ctrl + колёсико мыши |
| Переместиться по большому полю | Полосы прокрутки |

Внешнюю рамку изменять нельзя. Старт и выход нельзя закрасить стеной или
совместить при редактировании. Их координаты показаны справа в нижней
строке окна в формате `(строка, столбец)`, начиная с нуля.

### Поиск и визуализация

1. Выберите алгоритм и режим **«Анимация»** или **«Мгновенно»**.
2. Нажмите **«Запустить»**. Расчёт выполняется в фоновом потоке.
3. В режиме анимации управляйте воспроизведением кнопками
   **«Пауза / Продолжить»**, **«Шаг»** и **«Сбросить анимацию»**.

Алгоритм сначала вычисляет результат и сохраняет последовательность событий,
затем программа воспроизводит её. Сначала показываются события поиска,
после них — найденный путь. Если пути нет, исследованные клетки всё равно
можно просмотреть.

Кнопка **«Шаг»** останавливает автоматическое воспроизведение и показывает
следующее событие поиска или следующую клетку итогового пути. Её можно
нажать и до запуска: программа выполнит расчёт и покажет первый шаг.
Задержка между шагами настраивается от 0 до 1000 мс.

**«Сбросить анимацию»** убирает подсветку поиска, сохраняя лабиринт.
При смене алгоритма или редактировании поля прежнее воспроизведение
также сбрасывается.

| Цвет | Значение |
| --- | --- |
| Тёмный | Стена |
| Белый | Свободная клетка |
| Зелёный | Старт |
| Красный | Выход |
| Фиолетовый | Открытый список: клетки, ожидающие обработки |
| Голубой | Закрытый список: обработанные клетки |
| Жёлтый | Найденный путь |

### Результаты и сравнение

В таблице **«Последний запуск»** отображаются алгоритм, длина пути,
количество обработанных клеток и время расчёта в миллисекундах.
Длина пути — число переходов: маршрут из трёх клеток имеет длину 2.

Кнопка **«Сравнить алгоритмы»** запускает все пять алгоритмов на текущем
лабиринте и заполняет отдельную таблицу. Каждый алгоритм измеряется один раз;
показанное время включает формирование результата и событий поиска,
но не включает воспроизведение анимации. Время отдельных запусков может
различаться, поэтому для экспериментов нужны повторные измерения.

## Файлы лабиринтов

Кнопки **«Сохранить в файл»** и **«Загрузить из файла»** работают с JSON.
Сохраняются матрица, координаты старта и выхода и версия формата.
Подсветка поиска и таблицы результатов в файл не записываются.

Пример корректного файла размером 5 × 5:

```json
{
  "version": 1,
  "grid": [
    [1, 1, 1, 1, 1],
    [1, 2, 0, 0, 1],
    [1, 1, 1, 0, 1],
    [1, 0, 0, 3, 1],
    [1, 1, 1, 1, 1]
  ],
  "start": [1, 1],
  "end": [3, 3]
}
```

Значения матрицы: `0` — проход, `1` — стена, `2` — старт, `3` — выход.
Все строки должны иметь одинаковую длину, рамка должна состоять из стен,
а старт и выход должны встречаться ровно по одному разу и соответствовать
сохранённым координатам.

Текущие ограничения: от 5 до 2001 клетки по каждой стороне, размер
загружаемого файла — не более 10 МиБ. При размере больше 599 клеток
хотя бы по одной стороне программа запрашивает подтверждение:
большие лабиринты требуют больше времени и памяти.

## Сборка Windows-приложения (.exe)

Windows-версия собирается **в Windows**. PyInstaller включает интерпретатор
Python и необходимые библиотеки в приложение: на компьютере пользователя
отдельная установка Python и PyQt6 не требуется.
Сборка в Linux создаёт приложение для Linux, а не Windows `.exe`.
См. [документацию PyInstaller](https://pyinstaller.org/en/stable/).

После установки зависимостей по инструкции выше выполните в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name ProjectLabyrinth gui.py
```

Результат сборки — `dist\ProjectLabyrinth.exe`. Для передачи приложения
достаточно этого файла. Перед распространением проверьте запуск, генерацию,
поиск, сохранение и загрузку на целевом компьютере с Windows.

Параметр `--onefile` создаёт один исполняемый файл, а `--windowed` убирает
консольное окно. Описание параметров есть в
[руководстве по сборке](https://pyinstaller.org/en/stable/usage.html).

## Тестирование

В наборе пять основных тестовых сценариев: допустимый маршрут,
кратчайший путь, отсутствие пути, совпадение старта с выходом и
недопустимые координаты. С учётом повторения для разных алгоритмов
pytest выполняет 24 проверки. DFS не участвует в проверке кратчайшего пути.

В Windows:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -v
```

В Linux:

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -v
```

Подробности: [запуск и разбор тестов](docs/testing.md),
[описание сценариев](docs/test-cases.md).
