# ProjectLabyrinth

Промежуточная консольная версия курсовой работы по поиску пути в лабиринте.
Для запуска нужен Python 3.10 или новее; сторонние библиотеки не требуются.

```bash
python3 main.py
```

При запуске создаётся лабиринт 10×10. В меню можно запустить BFS,
двунаправленный BFS, алгоритм Дейкстры или A*, сравнить их на одном лабиринте, сгенерировать новое поле с размерами
не меньше 5 и снова показать исходное поле. Enter при вводе размера
выбирает значение 10. Для удобного показа в терминале подойдут размеры 10–25.

На поле `#` обозначает стену, `S` — старт, `E` — выход, `0` — найденный путь,
`.` — обработанные клетки вне пути. После поиска выводятся длина пути в шагах,
число обработанных клеток и время поиска без учёта печати. Исходный лабиринт
при показе решения не изменяется. Координаты имеют формат `(строка, столбец)`
и отсчитываются с нуля.

При сравнении каждый алгоритм запускается один раз. В таблице показано
время этого запуска. Между замерами карты не печатаются, а полные
результаты поиска освобождаются. Число обработанных клеток включает старт
и выход. Рядом с таблицей выводятся размеры поля и число проходимых клеток.

Графический интерфейс и остальные алгоритмы пока находятся в разработке.

Модульные тесты запускаются через pytest:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest
```

Описание проверок и команды запуска приведены в [документации по тестированию](docs/testing.md).
